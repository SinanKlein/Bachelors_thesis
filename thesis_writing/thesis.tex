\begin{abstract}
Bacteriophages shape the composition of the human gut microbiome, but which phage infects which bacterium is
rarely observed directly. Two proxies can be derived from sequencing data: a CRISPR spacer matching a viral genome,
which records a past infection of the bacterial lineage, and a co-abundance edge estimated by a graphical lasso.
This thesis predicts both of the proxies from the same representation, in which bacterial genera and viral
operational taxonomic units are described only by protein clusters formed \emph{de novo} within each cohort.
No functional annotation is used. Additionally, we train and evaluate each model on the identical set of
genus--vOTU pairs, on identical folds, in three independent cohorts, and ask whether one latent
representation can serve both.

The two targets behave very differently. CRISPR linkage reaches 0.78--0.81 AUC across cohorts, while the
co-abundance edge is predicted consistently above chance but far more weakly, at 0.55--0.61, with negative
$R^2$ throughout for regression on the continuous edge probability. The weak signal does not improve
with a change in the model, representation, binarisation threshold or taxonomic resolution. A joint model trained on 
both targets does not unify them. Even though it results in a small gain for the co-abundance task, it has no clear benefit
for the CRISPR task. Additionally, the small gain survives even when the CRISPR labels are permuted, which
implies that the CRISPR task acts as a regulariser for the co-abundance task rather than as a source of
shared signal. The one component of this pipeline carrying 
explicit biological information is the CRISPR target; where it entered, the signal is strong, and where it did not, 
only a weak one remains.
\end{abstract}

\section{Electronic appendix}
\label{el_app}

The electronic appendix accompanies this thesis and contains everything needed to reproduce it. It is
organised in three parts.

\textbf{Code.} The complete pipeline, as a set of independently runnable stages driven by a single
configuration file, together with the R scripts that draw every figure, the static test suite, and a README
describing the stage order and the outputs of each stage. The package versions and installation instructions
are included with it.

\textbf{Run outputs.} The three cohort runs on which this thesis is based, one directory per cohort, each
holding the frozen configuration used for that run, the preprocessed features, the fold assignments, the
per-fold predictions and metrics, and the outputs of the ablation, the threshold sweep, the latent export and
the shuffled-$y$ control. The runs are \texttt{20260815\_143422} (CRC), \texttt{20260815\_174444} (IBD) and
\texttt{20260815\_202259} (GvHD); every figure and table in this thesis is drawn from these three.

\textbf{Figures.} All figures produced by the pipeline, including the descriptive and diagnostic views that
are not reproduced in Section~\ref{app} because no statement in the text depends on them.
