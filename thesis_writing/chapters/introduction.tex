\subsection{Motivation and overview}
\label{intro:overview}
One interaction system can be represented by several networks, each built from a different kind of
evidence and each emphasising different structure. One example for such systems is phage--bacteria interaction. a
network can be assembled from sequence evidence by matching CRISPR spacers to viral genomes
\citep{edwards2016}, or estimated from abundance data with a statistical model \citep{kurtz2015}. The two
constructions have different strengths, and neither is a direct record of infection.

Let \(z\) be a feature
vector describing a bacterium--virus pair and let \(Y\) and \(W\) be the two networks. Each can be
predicted from \(z\) using its own representation. One could therefore ask whether a single
representation \(H=h(z)\) supports both without substantial loss. If it does, the two networks are
predictable from largely the same information; if it does not, they draw on different parts of \(z\).

The thesis addresses this using protein cluster profiles of genus--vOTU pairs in three gut microbiome
cohorts, in five steps. We fix a pair-level feature representation, measure how well each network can be
predicted from it using models of increasing flexibility, fit a model in which one representation feeds
both networks, compare the representation that model learns with the ones each network induces on its
own, and test by label permutation whether any gain reflects information shared between the networks or
the joint fitting procedure alone.

\subsection{Related Work}
The problem studied here belongs to a general class of problems: predicting an outcome for a pair of
entities from features of the two members. Drug--target and protein--protein interaction prediction have the same shape,
and the evaluation pitfall they share is directly relevant. \citet{park2012} show that holding out pairs
and holding out entities give very different estimates of performance, because a model can succeed on a
new pairing of two familiar entities without generalising to an unseen one.

Whether one representation can serve several prediction problems at once is the question of multi-task
learning, introduced by \citet{caruana1997} and reviewed by \citet{ruder2017}. A representation shaped by
all of the problems may generalise better than one fitted to each separately, but it may also be dominated
by whichever problem contributes the larger gradient. Comparing what such models actually learn requires a similarity measure that does not depend on
the arbitrary coordinates of a hidden layer, for which linear centred kernel alignment
\citep{kornblith2019} is the standard choice.

The instance studied here is phage--bacteria interaction, an established computational problem. Most
approaches use genome-derived information, such as matching CRISPR spacers, identifying phage sequences
inside bacterial genomes, or comparing sequence composition, and are evaluated against reference
collections in which the host is already known \citep{edwards2016,nie2024,shang2025}. The closest are
RaFAH \citep{coutinho2021}, which predicts host taxonomy from viral protein content, and iPHoP
\citep{roux2023}, which combines several sequence-derived signals. A separate line of work infers
association networks from abundance data \citep{kurtz2015}, where an edge represents a statistical
association whose ecological interpretation is not necessarily direct
\citep{coenen2018,pinto2022,alrasheed2019}.

This thesis differs in two respects. We represent the organisms by protein clusters built within each
cohort rather than by curated annotation, which avoids the dependency on reference databases that
annotation-based profiling such as PICRUSt2 \citep{douglas2020} carries, and which matters here because
annotation coverage is far sparser for gut phages than for bacteria. We also treat CRISPR linkage and the
edge selection probability as two networks predicted from the same feature space, so a prediction is made
for every genus--vOTU pair rather than a single host assignment per virus.

\subsection{Research questions and outline}
\label{intro:questions}
The thesis addresses three questions.

\begin{enumerate}
  \item To what extent can the two interaction networks be predicted from the pair-level feature representation?
  \item Does nonlinear modelling provide a substantial advantage over linear modelling?
  \item Does a shared representation predict both networks as well as separate ones, and is the
        representation it learns common to both?
\end{enumerate}
