\subsection{Implementation and reproducibility}
The full pipeline, from raw data to the figures and tables in this thesis, is implemented in code
provided in electronic form (Section~\ref{el_app}), together with the package versions and
installation instructions needed to run it.

Every stage runs under a fixed random seed, so that the ten folds, model initialisations and any
random subsampling are identical across repeated runs of the same configuration. This fixes the
stochastic parts of the pipeline but does not guarantee bit-identical results across different
hardware or library versions.
